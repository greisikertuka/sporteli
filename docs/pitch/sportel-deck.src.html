FirmatGroup · Track D · AI4Society Hackathon 2026 · Checkpoint 1

One place for Elbasan's municipal data. Any department export is onboarded in minutes, then turned into KPIs, trends and answers leadership can trust. This is our plan for the next 30 hours.

The problem

Data lives in separate department systems

  • Nobody gets one view of services, operations and citizen requests
  • Numbers are copied by hand from spreadsheet to spreadsheet
  • Reports reach leadership late, and no one can check where a number came from
Who it's for

Three users, one task each

Leadership

See how the municipality is doing at a glance, and ask a question without waiting for an analyst.

Department heads

Track performance against targets and spot a growing backlog early.

Planning & reporting

A new export arrived: get it into the shared picture in minutes.

What we build · backend

Five backend modules

ModuleWhat it doesDone when
IngestRead CSV/XLSX, profile columns, flag personal fields, ask AI for a mapping, apply the confirmed mappingA package file loads with every row linked to its source file
Data modelShared tables: departments, services, requests, locations, budget, targets, sourcesFitted to the organisers' data package
MetricsRequests, resolved on time, overdue, budget vs. actual, by department and monthNumbers match a hand check on sample files
CopilotQuestion → SQL → safety check (read-only, one statement, allowed tables, row limit) → answerShows answer, SQL and source; refuses unsafe queries
APIREST endpoints for all of the above, with OpenAPI docsFrontend uses only this API, no mock data
What we build · frontend

From mock screens to a working app

Upload & map wizard

Upload a file, see each column with a sample value and the AI suggestion, correct it, confirm.

Live dashboard

KPI cards and charts read from the API, with filters for department and month, and targets shown.

Ask box

Type a question in Albanian or English; see the answer, a chart, the SQL and the source files.

Sources & report

List of loaded files with row counts and dates; monthly report built from real figures.

Each screen replaces its mock data with an API call. If the AI is unavailable, the screens still work and say so.

Use of AI

AI where it saves hours, never where it must be exact

Column mapping

A small model suggests mappings from column names and non-personal samples. A person always confirms.

Ask the data

Questions become read-only, allow-listed SQL. If the check fails, Sportel says "I can't answer" instead of guessing.

Not AI

KPIs and trend alerts are plain calculations. If AI is down or over budget, the dashboard and API keep working.

AI spend is tracked against the team's USD 25–50 budget. All AI tools we use are declared in Annex E.
