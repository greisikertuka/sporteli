# Elbasan Pulse — Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A generic, disclosed, non-core monorepo scaffold (API + web shell + CI) that Track D features plug into on-site.

**Architecture:** `api/` is a FastAPI service with a DuckDB connection factory and a Claude client wrapper; `web/` is a Next.js App Router shell with sq/en i18n, light/dark theme and a sidebar with empty pages. They talk over `/api/v1`. No Track D logic (no canonical model, ingest, copilot, signals).

**Tech Stack:** Python 3.12 + uv, FastAPI, DuckDB, anthropic SDK, pydantic-settings, pytest, ruff · Next.js (App Router, TS), Tailwind, shadcn/ui, next-intl, next-themes, ECharts · Docker Compose · GitHub Actions.

## Global Constraints

- Scaffold contains **no Track D logic** (spec §8); it is declared in Annex E.
- Models: `claude-haiku-4-5` (mapping), `claude-sonnet-5` (copilot/briefing) (spec §4.3).
- LLM failure must never crash the app; the wrapper returns an "unavailable" result (spec §6).
- API prefix `/api/v1`; OpenAPI served at `/docs` (spec §3.1).
- UI languages: Albanian (`sq`, default) and English (`en`).
- Secrets only via `.env` (git-ignored); `.env.example` committed.

### Task 1: API skeleton — config, health, DuckDB

**Files:** Create `api/pyproject.toml`, `api/app/{__init__,main,config}.py`, `api/app/warehouse/{__init__,db}.py`, `api/tests/{__init__,conftest,test_health,test_db}.py`

**Interfaces — Produces:**
- `app.config.Settings` / `get_settings() -> Settings` with `anthropic_api_key: str | None`, `duckdb_path: str`, `cors_origins: list[str]`, `llm_budget_usd: float`
- `app.warehouse.db.get_connection() -> duckdb.DuckDBPyConnection` (FastAPI dependency; one per request)
- `GET /api/v1/health -> {"status": "ok", "db": bool, "llm": bool, "version": str}`

- [ ] Write `test_health` (status 200, `status == "ok"`, `db is True`) and `test_db` (`select 42` returns 42 with a tmp path) → run, expect FAIL (import error).

### Task 2: API — Claude client wrapper with budget + graceful failure

**Files:** Create `api/app/llm/{__init__,client}.py`, `api/tests/test_llm.py`

**Interfaces — Produces:**
- `LLMResult(ok: bool, text: str | None, error: str | None, input_tokens: int, output_tokens: int)`
- `LLMClient.complete(prompt: str, *, system: str | None = None, model: str = MODEL_FAST, max_tokens: int = 1024) -> LLMResult`
- `LLMClient.available: bool`, `LLMClient.spent_usd: float`; constants `MODEL_FAST`, `MODEL_SMART`

- [ ] Tests: no key → `available is False` and `complete()` returns `ok=False, error="llm_unavailable"`; fake SDK raising → `ok=False`; fake SDK returning usage → `spent_usd > 0`; spent ≥ budget → `error="llm_budget_exhausted"`. Run → FAIL.
- [ ] Implement → PASS → commit `feat(api): Claude client wrapper with budget guard`.
