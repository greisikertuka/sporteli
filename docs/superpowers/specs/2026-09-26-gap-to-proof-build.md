## 0. Ground rules

- **Data honesty.** The organisers' data package is not on this machine. We build on **synthetic department exports** generated by `api/scripts/generate_samples.py` into `api/samples/`. Every synthetic file has `SINTETIKE` in its filename and title row, and the UI shows a "Të dhëna sintetike / Synthetic data" badge whenever a loaded source is synthetic. When the real package arrives, the team drops its files into the same pipeline; nothing is hardcoded to the synthetic files except the demo seed list.
- **Code computes every number. The LLM never types a digit.** AI is used only for (a) proposing column→field mappings, (b) routing a free-text question to a passport or a guarded SELECT. All answer text is templated with values formatted by code.
- **Works without AI.** No `ANTHROPIC_API_KEY` on this machine. Every AI path has a deterministic fallback; the UI shows mode `RREGULLA / RULES` when AI is unavailable and `AI LIVE` when it is. Never fake an AI call.
- **Privacy.** Personal columns (names, phones, emails, Albanian personal numbers, street addresses) are detected and dropped **before** profiling samples are built and before any LLM call. Only headers, inferred types and at most 5 masked sample values per non-personal column may be sent to the model; never rows. Every LLM call is logged in `llm_call` with a summary of what was sent.
- **Political guardrails (UI copy).** Never say a municipality's numbers are wrong or its process is manual/broken. Formula status is "draft — awaiting validation" (`formula_status: draft`) unless validated. Owners are role-based placeholders (see §2) configurable in `catalog.py` — replace them with names confirmed at the municipal desk.
- **Bilingual.** UI default Albanian (`sq`), English toggle. Every user-facing string from the API is an `L10n` object `{ "sq": "...", "en": "..." }`.
- Style: match existing code. Python 3.12, FastAPI, DuckDB, ruff (line length 100). Web: Next.js 16 (read `web/node_modules/next/dist/docs/` before using any Next API — this version has breaking changes; `middleware.ts` is now `proxy.ts`), React 19, Tailwind 4, the existing civic CSS in `web/src/app/globals.css`, next-intl, ECharts, lucide-react.
- Tooling on this Windows machine: in Git Bash, run pnpm as `cmd //c "pnpm <args>"` (the bash pnpm shim is broken) or use the PowerShell tool. Python: `cd api && uv run ...`. Do **not** start servers on ports 8000/3000 (reserved for the human's preview); use 8100-8199 / 3100-3199 if you need a live server, and stop it when done. Do not run `taskkill /IM python.exe` or kill processes you did not start.
- Do not `git commit` unless your task says so. Do not touch `docs/pitch/*` files you did not create, or any untracked file you did not create.

## 2. Catalog and canonical model (`api/app/catalog.py`, `api/app/warehouse/schema.py`)

`catalog.py` is the single source of truth for datasets, fields, synonyms (for rule-based mapping), owners, and which passports each dataset unlocks.

Owners (role-based placeholders, configurable):

| key | sq | en |
|---|---|---|
| citizen_relations | Sektori i Marrëdhënieve me Qytetarët | Citizen Relations Sector |
| finance | Drejtoria e Financës dhe Buxhetit | Finance and Budget Directorate |
| public_services | Drejtoria e Shërbimeve Publike | Public Services Directorate |
| local_revenue | Drejtoria e të Ardhurave Vendore | Local Revenue Directorate |
| hr | Drejtoria e Burimeve Njerëzore | Human Resources Directorate |
| statistics | Sektori i Statistikës dhe Performancës | Statistics and Performance Sector |

Datasets → tables (every fact row has `source_id VARCHAR`, `row_no INTEGER` = 1-based row number in the original file/sheet):

- `requests` → `request(source_id, row_no, request_id, created_at DATE, closed_at DATE, category, department, admin_unit, channel, status, sla_days INTEGER)`; required: request_id, created_at, category, status. Owner: citizen_relations.
- `budget` → `budget_line(source_id, row_no, month DATE, programme_code, programme, line_type, planned_lek DOUBLE, actual_lek DOUBLE)`; `line_type` normalised to `current`/`capital`; required: month, programme_code, planned_lek, actual_lek. Owner: finance.
- `waste` → `waste_collection(source_id, row_no, month DATE, admin_unit, tonnes DOUBLE, trips INTEGER, households_served INTEGER)`; required: month, admin_unit, tonnes. Owner: public_services.
- `revenue` → `revenue(source_id, row_no, month DATE, revenue_type, payer_type, planned_lek DOUBLE, collected_lek DOUBLE)`; required: month, revenue_type, collected_lek. Owner: local_revenue.
- `staff` → `staff(source_id, row_no, department, headcount INTEGER, hires INTEGER, leavers INTEGER, as_of DATE)`; required: department, headcount. Owner: hr.
- `population` (reference) → `population(source_id, row_no, admin_unit, basis, residents INTEGER)`; owner: statistics.

Admin units are normalised on load (strip, casefold, remove diacritics, map known variants such as `Shirgjani`→`Shirgjan`). Money in `(000 lekë)` columns is multiplied by 1,000 on load (the receipt states the multiplier).

System tables: `source(id, filename, file_hash, dataset, sheet, header_row, header_fingerprint, synthetic BOOLEAN, rows_read, rows_loaded, rows_excluded_json, reconciliation_json, pii_dropped_json, unit_multiplier, mapping_json, recipe_id, recipe_reused BOOLEAN, llm_json, loaded_at TIMESTAMP, duration_ms)`, `mapping_recipe(id, dataset, header_fingerprint, mapping_json, created_at, from_filename)`, `llm_call(id, ts, purpose, model, input_tokens, output_tokens, cost_usd, latency_ms, ok, error, sent_json)`, `definition_pin(key, value, pinned_at, reason)`, `signal_ack(indicator_code, rule, status, reason, ts)`.

Database access: one process-wide DuckDB connection (`app.warehouse.db.get_db()`), request handlers use `con.cursor()`. Tests use a temp path via `DUCKDB_PATH`.

## 4. Ingest pipeline (`api/app/ingest/`)

`preview(file_bytes, filename) → IngestPreview`, `commit(preview_id, dataset, mapping, save_recipe) → LoadReceipt`, and `ingest_path(path, dataset=None, *, save_recipe=False) → LoadReceipt` (used by the seed). Steps, each reported as an `IngestStep` with a real result:

1. read (CSV: sniff delimiter, try utf-8-sig then cp1252; XLSX via openpyxl with merged cells forward-filled; XLS via xlrd) — first sheet with data;
2. detect header row (first row whose cells are mostly non-empty strings after title rows), detect unit hints like `(000 lekë)`;
3. exclude total/subtotal/blank rows (`TOTALI`, `Gjithsej`, `Shuma`, `Total`) and keep them for reconciliation;
4. PII gate (header keywords + value regexes: `+355`/`06x` phones, emails, Albanian personal number `[A-T]\d{8}[A-W]`) → dropped columns;
5. profile columns (type inference incl. Albanian dates `dd.mm.yyyy`, month names, `YYYY-MM`, decimal comma);
6. recipe lookup by header fingerprint (hash of normalised header list + dataset); on a partial match report `drift` (renamed/missing/added) and fall back to mapping;
7. mapping: Claude Haiku 4.5 structured output (one call per file: headers + types + ≤5 masked samples per non-PII column → per column `field|null`, `confidence`, `reason`, and at most one clarifying question) with a deterministic fallback (synonyms + rapidfuzz, confidence capped at 0.6 so everything shows amber and needs a click);
8. on commit: coerce types, apply unit multiplier, normalise admin units, insert rows with `source_id` + `row_no`, reconcile sums against the file's total row, save recipe (if requested), compute `indicators_unlocked` and new coverage.

## 5. Signals (plausibility checks)

Generic rules evaluated per passport series/value; each produces `Signal { rule, severity, message (L10n), period }`:
`placeholder_value` (0 or 1 or a repeated constant in a series where neighbours are large), `swing` (month-over-month change > 50% while the base is non-trivial), `rate_bounds` (a percentage outside 0–100), `off_target` (latest value on the wrong side of target), `parts_vs_total` (ingest reconciliation mismatch). Copy is neutral ("kontrolloni sasinë ose njësinë" — "check the quantity or unit"), never accusatory.

## 6. Copilot (`api/app/copilot/`, `api/app/sqlguard/`)

`POST /ask` decides the label **in code**:
- `verified`: routed to a passport (exact example id, deterministic matcher over `question`+`aliases` with diacritic-insensitive token overlap, or the LLM's structured intent) and all its datasets are loaded → value from `value_sql`, answer from the passport template, SQL + sources shown.
- `not_answerable`: routed to a passport (or topic keyword like "mbetje/waste", "taksa/tax", "punonjës/staff") whose datasets are missing → gap card naming the missing export and its owner, from the catalog; no number.
- `exploratory`: free text that the LLM turns into a single SELECT which passes the guard → run in the sandbox, show SQL + result table; answer text is templated ("Rezultati i pyetjes eksploruese…"), never LLM prose containing numbers.
- `blocked`: write/DDL statements, multiple statements, non-allowlisted tables, personal fields, or requests for individual-level personal data → reason shown.
Without AI, free text that the matcher cannot route → `not_answerable` with reason "AI offline — try an example question".

Guard: sqlglot parse (DuckDB dialect), exactly one statement, SELECT only, tables ⊆ allowlist (canonical fact tables), no table functions / `read_*` / `COPY` / `ATTACH` / pragmas, wrap with `LIMIT 200`. Sandbox: an in-memory DuckDB connection with allowlisted tables registered from Arrow snapshots, `SET enable_external_access=false`, `SET lock_configuration=true`, timeout via `interrupt()`.

Eval: `api/tests/golden/golden_set.yaml` (24 questions: 12 sq, 12 en; mix of verified, not_answerable, blocked, exploratory-expected), `api/scripts/run_eval.py` writes `api/eval_result.json` (`run_at`, `commit`, `mode`, per-label matched/total). Expected values are computed independently from the raw sample files in the test, not from the passports.
